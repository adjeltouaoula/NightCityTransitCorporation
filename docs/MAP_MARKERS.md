# NCTC map markers

Every stop needs three separately verified positions before a marker can become
an operational stop:

1. `terminalPosition` — passenger-side NCTC terminal;
2. `kerbPosition` — where the bus opens its right-side door;
3. `approachPosition` — traffic-lane spawn/approach point.

The map layer is green and independently toggleable from other mods' markers.
No provisional coordinate is shipped: a wrong green marker is worse than no
marker because it sends the player to the wrong pavement.
